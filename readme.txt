■ 概要

Excel / Access の VBA コードを、VBE（Visual Basic Editor）から
ショートカットキー 1 つでインデント整形するアドインです。

・DLL 1 つ（約 90KB）の軽量なアドインで、Office の起動を遅くしません。
・メニュー、右クリックメニュー、ショートカットキーから実行できます。
・インストールに管理者権限は不要です。
  「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」の設定も不要です。
・インデントだけを直し、行数は変えないので、ブレークポイントの位置もずれません。
・画面は日本語 / 英語に対応し、Office の表示言語に合わせて自動で切り替わります。


■ インストール

1. Excel / Access など、Office をすべて終了します。
2. ダウンロードした zip を右クリック →「プロパティ」→「全般」タブ下部の
   「許可する」にチェックを入れて「OK」を押します。
3. zip を展開し、install.bat をダブルクリックします。
4. Office を起動して Alt+F11 で VBE を開くと、メニューバーに「整形(J)」が
   追加されています。

※ 手順 2 を省くと、「Windows によって PC が保護されました」などの警告が出る
  ことがあります。その場合は「詳細情報」→「実行」で続行できます。
※ インストール先は %LOCALAPPDATA%\SnapIndenter です。
  設定は %APPDATA%\SnapIndenter\settings.ini に保存されます。
※ install.bat は同梱の install.ps1（PowerShell スクリプト）を実行し、
  DLL のコピーと、現在のユーザーのレジストリ（HKCU）への登録を行います。


■ アンインストール

Windows の「設定 → アプリ → インストールされているアプリ」で SnapIndenter を
選んで「アンインストール」を押すか、uninstall.bat を実行します。
Office を終了してから行ってください。
インストールしたファイルとレジストリの登録をすべて削除します。


■ 使い方

  カーソル位置のプロシージャを整形          Ctrl+Shift+F
  （複数行を選択しているときは選択範囲）
  表示中のモジュール全体を整形              Ctrl+Shift+M
  プロジェクト全体を整形                    メニューから
  直前の整形を元に戻す                      メニューから
  設定（プレビュー付き）                    メニューから

メニューバーの「整形(J)」と、コード ウィンドウの右クリックメニューから実行できます。
ショートカットキー、インデント幅、タブの使用、Case をインデントするかどうか、
表示言語などは設定画面で変更できます。

※ VBE の Ctrl+Z ではアドインによる変更を戻せません。
  「直前の整形を元に戻す」を使ってください。

詳しい仕様は、同梱の docs\仕様書.md を参照してください。
